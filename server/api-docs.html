LMS Nusa API

API for client systems: Reading Log and External Training.

Overview Authentication Reading Log: Categories Report reading External Training: New request Errors

Overview

Base URL: https://lms.example.com

Responses are JSON. Every call except the token request needs the header Authorization: Bearer <access_token>. Employees are identified by their LMS email.

APIEndpointUse it to
AuthenticationPOST /api/oauth/tokenGet an access token
Reading LogGET /api/external/v1/reading-logs/categoriesList the valid book categories
Reading LogPOST /api/external/v1/reading-logsReport a finished personal book
External TrainingPOST /api/external/v1/external-trainingsFile a new external training request, already approved by the employee's leader

Authentication

POST/api/oauth/token

Exchanges your client credentials for an access token (OAuth2 client_credentials). The token is valid for expires_in seconds (1 hour by default); request a new one when it expires.

FieldDescription
grant_type requiredAlways client_credentials
client_id requiredProvided by the LMS team
client_secret requiredProvided by the LMS team. Keep it secret.

Example

curl -X POST https://lms.example.com/api/oauth/token \
  -H "Content-Type: application/json" \
  -d '{ "grant_type": "client_credentials", "client_id": "CLIENT_ID", "client_secret": "CLIENT_SECRET" }'

Response 200

{ "access_token": "eyJjaWQiOi...abc", "token_type": "Bearer", "expires_in": 3600 }

Reading Log

Report books employees have finished reading, the same as Report Private Reading in the LMS.

Categories

GET/api/external/v1/reading-logs/categories

Returns the valid values for the category field of Report reading. Use it to fill a picker instead of hardcoding or typing categories; the list can change over time.

Example

curl https://lms.example.com/api/external/v1/reading-logs/categories \
  -H "Authorization: Bearer <access_token>"

Response 200

{ "categories": [{{CATEGORIES_JSON}}] }

Current categories:

    {{CATEGORIES}}

Report reading

POST/api/external/v1/reading-logs

Reports a finished personal book, the same as the Report Private Reading form in the LMS. The log is saved as Finished with hr_approval_status: "Draft" and appears to HR as a personal book. The employee then claims the incentive in the LMS.

Send it as multipart/form-data (not JSON), because it includes the evidence photo.

FieldDescription
email requiredEmployee's LMS email (case-insensitive)
title requiredBook title
category requiredOne of the values from Categories (case-insensitive)
start_date requiredWhen reading started. ISO 8601, e.g. 2026-10-01 or 2026-10-01T09:00:00+07:00
finish_date requiredWhen reading finished. ISO 8601. Must be more than 1 day after start_date
review_link requiredLink to the employee's book review
evidence requiredEvidence photo file (image, max 10 MB)
authorBook author

Example

curl -X POST https://lms.example.com/api/external/v1/reading-logs \
  -H "Authorization: Bearer <access_token>" \
  -F "email=employee@nusa.id" \
  -F "title=Atomic Habits" \
  -F "category=Buku Pengembangan Diri" \
  -F "author=James Clear" \
  -F "start_date=2026-10-01" \
  -F "finish_date=2026-10-15" \
  -F "review_link=https://docs.google.com/document/d/xxxx" \
  -F "evidence=@/path/to/photo.jpg"

Response 201

  "name": "Budi Santoso",
  "title": "Atomic Habits",

External Training

File external training requests, the same as New Request on the External Training page in the LMS.

New request

POST/api/external/v1/external-trainings

Creates an external training request that is already approved by the employee's leader (the same leader who would approve it in the LMS; taken from the org chart), so it skips the leader's approval step and goes straight to HR to process. The status is Approved.

Send it as multipart/form-data, because it can include an attachment file.

Training categories

Only these 3 values are accepted. Send the value; it is what's saved in the database. The LMS shows it with the label on the right.

Value to sendShown in the LMS as (EN)Shown in the LMS as (ID)
SertifikatTraining with Competency CertificationPelatihan dengan Sertifikasi Kompetensi
TrainingTraining with Certificate of ParticipationPelatihan dengan Sertifikat Kepesertaan
ModulE-Learning / Self-Paced LearningE-Learning / Pembelajaran Mandiri

Fields

FieldDescription
email requiredEmployee's LMS email (case-insensitive)
category requiredOne of the 3 values in Training categories below (case-insensitive)
title requiredTraining name
vendor requiredTraining provider
location requiredWhere it takes place, e.g. Online or a city
start_date requiredISO 8601, e.g. 2026-11-03. A date without a time is read as WIB (UTC+7)
end_date requiredISO 8601. Cannot be before start_date
registration_feeFee in Rupiah, number only (e.g. 2500000). Default: 0 (free)
payment_methodReimbursement or Direct Payment. Required when registration_fee is more than 0
attachmentAttachment file (image or PDF, max 10 MB), e.g. a brochure or invoice
attachment_linkLink instead of a file (e.g. the course page). Only for category Modul, same as the LMS form. Send either attachment or attachment_link, not both
cc_emailsEmails of employees to CC, comma-separated. They're notified if this request goes over the employee's personal learning budget
approval_noteThe leader's approval note. Default: Approved via external API

Example

curl -X POST https://lms.example.com/api/external/v1/external-trainings \
  -H "Authorization: Bearer <access_token>" \
  -F "email=employee@nusa.id" \
  -F "category=Training" \
  -F "title=AWS Solutions Architect Associate" \
  -F "vendor=Training Provider" \
  -F "location=Jakarta" \
  -F "start_date=2026-11-03" \
  -F "end_date=2026-11-04" \
  -F "registration_fee=2500000" \
  -F "payment_method=Direct Payment" \
  -F "cc_emails=manager@nusa.id" \
  -F "approval_note=Approved in the client system" \
  -F "attachment=@/path/to/brochure.pdf"

Errors

Errors return { "error": "...", "error_description": "..." }.

StatusMeaning
401Missing, invalid, or expired access token. Request a new token.
400Missing required field, file of the wrong type or over 10 MB, unknown category, invalid date, or a field breaking a rule above (e.g. reading period of 1 day or less, fee without payment_method, unknown cc_emails).
404Email not registered in the LMS.
409Already submitted, e.g. a retried request. Reading Log: same email, title, start and finish date; the response includes the existing reading_log. External Training: same email, title and start date; the response includes the existing external_training.
422External Training: the employee has no active leader set in the LMS, so the request can't be filed as leader-approved. Ask the LMS team to fix the employee's leader.
500Server error. Retry later or contact the LMS team.
